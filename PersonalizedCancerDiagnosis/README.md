# Personalized Cancer Diagnosis

Machine learning project to classify **genetic mutations into 9 cancer-related classes** using genetic variation and clinical text data.

## 🔄 Workflow

```text
Genetic + Clinical Data
→ EDA & Preprocessing
→ Feature Engineering
→ Text Vectorization / Response Coding
→ Model Training
→ Hyperparameter Tuning
→ Model Evaluation
```

## 🤖 Models

- Logistic Regression
- Linear SVM
- Naive Bayes
- Random Forest
- SGD Classifier
- XGBoost
- Stacking Ensemble

## 📊 Evaluation

- Multi-class Log Loss
- Confusion Matrix
- Cross-Validation

## 🛠️ Tech Stack

Python • Pandas • NumPy • Scikit-learn • NLTK • XGBoost • Matplotlib • Seaborn

```text
dataset/

```
