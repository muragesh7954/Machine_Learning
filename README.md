# Machine Learning Projects

A collection of end-to-end Machine Learning projects covering data preprocessing, exploratory data analysis, feature engineering, model development, evaluation, and model comparison.

The projects are organized independently, with each project containing its own dataset, notebooks, source code, and documentation.

---

# 🧠 Machine Learning Workflow

The projects generally follow an end-to-end machine learning workflow:

```text
Dataset
   ↓
Data Loading
   ↓
Data Cleaning
   ↓
Exploratory Data Analysis
   ↓
Univariate Analysis
   ↓
Bivariate Analysis
   ↓
Multivariate Analysis
   ↓
Feature Engineering
   ↓
Feature Selection
   ↓
Train / Validation / Test Split
   ↓
Model Training
   ↓
Hyperparameter Tuning
   ↓
Model Evaluation
   ↓
Model Comparison
   ↓
Final Model
```
